=========================================
اپ اندروید ValveBox — راهنمای کامل نصب
(نسخه‌ی نهایی، با ۶ قابلیت امنیتی/مدیریتی)
=========================================

این پروژه شامل همه‌چیز است:
  - کد کامل اپ اندروید
  - فایل app.py کامل هاب (در ریشه‌ی این پوشه)
  - قابلیت‌های جدید: پوش فوری (Firebase)، ضدحمله به ورود، پنل مدیریت،
    پشتیبان‌گیری خودکار، گزارش هوشمند، لاگ فعالیت

===========================================================
بخش ۱ — جایگزینی app.py و ری‌استارت سرویس واقعی
===========================================================

توجه: سرور شما با systemd اجرا می‌شود (سرویس valvebox-hub.service)،
نه با اجرای دستی uvicorn. مسیر واقعی و محیط مجازی آن:
  WorkingDirectory: /home/saeed/valve_box/valvebox_hub
  Python venv:       /home/saeed/valve_box/venv311

۱) فایل app.py (ریشه‌ی این پوشه) را کامل کپی کن، جایگزین
   valvebox_hub/app.py کن.

۲) پکیج‌های جدید مورد نیاز را در همان venv نصب کن:
     /home/saeed/valve_box/venv311/bin/pip install requests google-auth

۳) سرویس را ری‌استارت کن:
     sudo systemctl restart valvebox-hub.service

۴) بررسی سلامت:
     systemctl status valvebox-hub.service
   اگر active (running) بدون خط قرمز خطا بود، موفق بوده.

===========================================================
بخش ۲ — تنظیمات .env (برای بازیابی رمز + گزارش هوشمند اختیاری)
===========================================================

این خطوط را به valvebox_hub/.env اضافه/تکمیل کن:

  VALVEBOX_GMAIL_ADDRESS=saeedrostami2081@gmail.com
  VALVEBOX_GMAIL_APP_PASSWORD=ptwjhvybexayqqns
  VALVEBOX_HUB_PUBLIC_URL=https://valvebox.ir

  # اختیاری — فقط اگر می‌خواهی گزارش تاریخچه به‌صورت روایی و با هوش
  # مصنوعی هم نوشته شود (هزینه دارد). بدون این خط، گزارش فقط به‌صورت
  # آمار خام (رایگان) نمایش داده می‌شود.
  ANTHROPIC_API_KEY=

  # اختیاری — فقط اگر پوش فوری فایربیس را راه‌اندازی کردی (بخش ۴)
  VALVEBOX_FIREBASE_PROJECT_ID=
  VALVEBOX_FIREBASE_SERVICE_ACCOUNT_FILE=

بعد از تغییر .env، دوباره سرویس را ری‌استارت کن:
  sudo systemctl restart valvebox-hub.service

===========================================================
بخش ۳ — استفاده از پنل مدیریت (بدون نیاز به SSH)
===========================================================

با کاربری که level آن ۳ است (مثل admin) وارد سایت شو. حالا بالای
صفحه‌ی دستگاه‌ها یک لینک «پنل مدیریت» می‌بینی. از آنجا می‌توانی:
  - دستگاه و کاربر جدید اضافه/حذف کنی (بدون نیاز به ویرایش دستی JSON)
  - پشتیبان بگیری و دانلود کنی
  - لاگ فعالیت کاربران را ببینی
  - گزارش تاریخچه‌ی هر دستگاه را بسازی

===========================================================
بخش ۴ — راه‌اندازی پوش نوتیفیکیشن فوری (Firebase) — اختیاری
===========================================================

این بخش نیاز به چند قدم دستی در کنسول گوگل دارد (رایگان، ولی من
نمی‌توانم جایت انجامش بدهم):

۱) برو به console.firebase.google.com، یک پروژه‌ی جدید بساز (مثلاً
   اسمش را ValveBox بگذار).

۲) داخل پروژه، «Add app» -> Android را بزن. Package name را دقیقاً
   این بنویس:
     ir.valvebox.app
   (بدون نیاز به SHA-1، می‌توانی ردش کنی)

۳) فایل google-services.json که دانلود می‌شود را بردار و داخل پوشه‌ی
   app (کنار همان app/build.gradle.kts) این پروژه‌ی اندروید بگذار.

۴) از تنظیمات پروژه‌ی فایربیس -> Service Accounts -> «Generate new
   private key» یک فایل JSON دیگر دانلود کن. این فایل را به Pi منتقل
   کن، مثلاً در مسیر:
     /home/saeed/valve_box/valvebox_hub/firebase-service-account.json

۵) در .env این دو خط را با مقادیر واقعی پر کن:
     VALVEBOX_FIREBASE_PROJECT_ID=آیدی‌پروژه‌ی‌فایربیست (در تنظیمات پروژه است)
     VALVEBOX_FIREBASE_SERVICE_ACCOUNT_FILE=/home/saeed/valve_box/valvebox_hub/firebase-service-account.json

۶) سرویس هاب را ری‌استارت کن.

۷) پروژه‌ی اندروید را دوباره در GitHub آپلود کن (این بار همراه با
   google-services.json که در همان پوشه‌ی app گذاشتی) و APK جدید را
   بساز و نصب کن.

اگر این بخش را رد کنی، همه‌چیز دیگر (از جمله اعلان دوره‌ای هر ۱۵
دقیقه که از قبل داشتیم) بدون مشکل کار می‌کند — فقط پوش فوری لحظه‌ای
نخواهی داشت.

===========================================================
بخش ۵ — آپلود پروژه‌ی اندروید در GitHub و ساخت APK
===========================================================

(دقیقاً مثل قبل)
۱) این زیپ را Extract کن.
۲) در ریپازیتوری GitHub، همه‌ی فایل‌های قدیمی را پاک کن.
۳) Add file -> Upload files، محتویات پوشه‌ی ValveBoxApp را (همراه با
   google-services.json اگر بخش ۴ را انجام دادی) drag & drop کن.
۴) Commit changes.
۵) تب Actions -> صبر کن سبز شود -> از Artifacts دانلود کن.
۶) نسخه‌ی قبلی اپ را از گوشی Uninstall کن، APK جدید را نصب کن.
